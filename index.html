Install a clean, ready-to-play SD card in a few clicks.

1. Choose your device

R36SX owners: choose the version printed by your stock firmware. v2.6 and v2.7 use separate backups.

2. Select the SD card

Choose the mounted card root. We’ll identify the block device before any destructive action.

3. Install TreeFrogUI

This erases the selected SD card.
It will be formatted as FAT32, restored from the matching stock backup, and overlaid with the latest TreeFrogUI release.
